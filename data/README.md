# Данные

Источник, указанный в исходном практикуме: [Industrial Robotic Arm — IMU Data (CASPER 1 & 2), Hakan Kayan](https://www.kaggle.com/datasets/hkayan/industrial-robotic-arm-imu-data-casper-1-and-2).

Связанная публикация: [Kayan et al., CASPER: Context-Aware IoT Anomaly Detection System for Smart Environments, 2024](https://ngcharithperera.gitlab.io/publications/pdfs/Kayan2024a.pdf).

Для воспроизведения положите предоставленный файл `IMU_10Hz.csv` в эту папку:

```text
data/
├── README.md
└── IMU_10Hz.csv    # локальный файл, не коммитить
```

В текущем анализе использована запись из 874 937 строк одного модуля IMU8. Это не полный набор CASPER: в статье описана исходная частота 20 Гц, а предоставленный файл имеет среднюю частоту около 10 Гц. Скрипт преобразования исходного датасета в эту версию не предоставлен. Поэтому скачивание другого CSV с Kaggle не гарантирует совпадение результатов; для точного воспроизведения нужна именно версия ниже.

Характеристики проверенной версии:

- Размер: 135 748 396 байт (около 129.46 MiB).
- SHA-256: `1221df9be80c229969f3f21f820837e68ad28f4ccb3949bf4013f00d6d69d62c`.
- Поля: `name,time,accX,accY,accZ,gyroX,gyroY,gyroZ,magX,magY,magZ`.
- Время хранится целыми числами в наносекундах; временные метки строго возрастают.
- Единицы сенсоров в ноутбуке — рабочие предположения исходного практикума, не подтверждённые метаданными CSV.

Проверить контрольную сумму на macOS:

```bash
shasum -a 256 data/IMU_10Hz.csv
```

CSV не включён в репозиторий: он превышает [лимит GitHub в 100 MiB](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github). Условия распространения конкретного преобразованного файла не установлены, поэтому проект даёт ссылку на источник без перепубликации данных. Лицензия кода, если будет добавлена автором, не распространяется автоматически на сторонний датасет.

Для другого расположения данных задайте переменную окружения `IMU_DATA_PATH` до запуска Jupyter либо измените `DATA_PATH` в начале ноутбука.
